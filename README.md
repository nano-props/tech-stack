# Tech Stack

A concise recommended stack for modern product development.

## Frontend

- **[Vue](https://github.com/vuejs/core)** — Build clean, intuitive interfaces with confidence.
- **[Vite](https://github.com/vitejs/vite)** — Lightning-fast starts and instant feedback while coding.
- **[Tailwind CSS](https://github.com/tailwindlabs/tailwindcss)** — Precision utilities for a refined, consistent UI.
- **[Zustand](https://github.com/pmndrs/zustand)** — Simple state handling for smooth user experiences.
- **[date-fns](https://github.com/date-fns/date-fns)** — Elegant, functional date utilities without bloat.
- **[es-toolkit](https://github.com/toss/es-toolkit)** — Practical essentials for cleaner JavaScript and TypeScript.
- **[Valibot](https://github.com/fabian-hiller/valibot)** — Lightweight validation with clear and predictable behavior.
- **[TanStack](https://github.com/TanStack)** — Data workflows designed for responsive front-end apps.
- **[Reka UI](https://github.com/unovue/reka-ui)** — Thoughtful Vue components for polished interaction.
- **[Prettier](https://github.com/prettier/prettier)** — Beautiful, consistent formatting every time.
- **[TypeScript](https://github.com/microsoft/TypeScript)** — Confidently scale code with precise types.
- **[Babel](https://github.com/babel/babel)** — Modern JavaScript, ready for broader compatibility.

## Backend

- **[Hono](https://github.com/honojs/hono)** — Minimal, fast APIs with a developer-friendly surface.
- **[croner](https://github.com/hexagon/croner)** — Reliable scheduling, designed to stay out of your way.
- **[p-queue](https://github.com/sindresorhus/p-queue)** — Gentle control over concurrency, retries, and flow.
- **[execa](https://github.com/sindresorhus/execa)** — Clean process control for scripts and automation.
- **[nanoid](https://github.com/ai/nanoid)** — Fast unique IDs with a tiny footprint.
- **[TypeScript](https://github.com/microsoft/TypeScript)** — Shared type discipline across your backend services.
- **[Prettier](https://github.com/prettier/prettier)** — Uniform style for maintainable server code.
- **[Babel](https://github.com/babel/babel)** — Smooth transpilation for stable runtime support.

## Shared / Cross-platform

- **[TypeScript](https://github.com/microsoft/TypeScript)** — One language for frontend and backend reliability.
- **[TanStack](https://github.com/TanStack)** — Composable libraries for polished data experiences.
- **[Prettier](https://github.com/prettier/prettier)** — Elegant consistency across the entire repo.
- **[Electron](https://github.com/electron/electron)** — Desktop apps built with web power and native feel.
